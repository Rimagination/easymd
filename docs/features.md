# 功能说明

easymd 现在聚焦在“微信公众号、知乎排版”这条主线，保留高频能力，去掉偏产品外扩的功能。

---

## 核心能力

### 编辑与预览

- CodeMirror 6 编辑器
- 实时预览
- 编辑区与预览区滚动同步
- 移动端 / 桌面端预览宽度切换

### 排版样式

- 内置多套 Markdown 排版样式
- 支持代码高亮主题
- 支持 Mermaid 与信息图主题设置
- 支持自定义 CSS 覆盖
- 支持导入 `.css` 文件并注册为自定义排版样式

### 导出与复制

- 复制为微信公众号格式
- 保留知乎复制入口，适配仍在继续完善
- 复制 HTML
- 导出图片
- 导出 PDF
- 打印预览

### 内容与文件

- 多文档标签管理
- 本地自动保存
- 导入 Markdown / HTML / 图片
- 导出 Markdown
- Markdown 格式化

### AI 集成

- 保留 MCP 协议
- `render`、`parse`、`extract`、`lint` 四个工具继续可用
- MCP 配置说明位于 `/docs/mcp`

---

## 已移除的能力

### 平台与接口

- 掘金复制支持
- REST API
- Scalar API 文档页 `/docs`

### 应用外壳

- PWA
- 安装到桌面
- 文件关联打开 `.md`
- 命令面板

---

## 当前更适合的使用方式

1. 在编辑区撰写或导入 Markdown
2. 在预览区选择排版样式或导入自定义 CSS
3. 通过底部按钮栏直接复制为微信公众号格式或知乎格式
4. 必要时导出 HTML、图片或 PDF
